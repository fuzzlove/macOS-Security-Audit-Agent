# Configuration reference

Defaults are in `mac_audit_agent/config/alerting.json` and the file is packaged with MSAA. Unsafe values fail validation. Key defaults: 10,000 admission capacity; 2,000 notification entries with 500 slots reserved from ordinary low-priority use; 50,000 active identities; 4,096 bounded source windows; 2 GiB logical quota with 256 MiB emergency reserve; 1,000 initial individual duplicate bodies plus first/latest/important records; 512 emergency fallback receipts; 1 MiB fallback journal; 256 KiB event size; 16 KiB strings; nesting depth 8; collection size 128; suppression duration at most 24 hours; summaries at 10, 100, 1,000, later powers of ten, and five-minute monotonic intervals during continuing activity.

These are initial defaults, not performance guarantees. Workstations and developer machines should begin with defaults and measure. Production and high-sensitivity endpoints should preserve the protected reserve and may lower ordinary desktop-notification/cardinality limits. Emergency Protection Mode should preserve protected raw records. Central monitoring nodes require a separate storage, concurrency, retention, and key-management assessment; this implementation is endpoint-local.
