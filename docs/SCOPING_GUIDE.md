# Scoping workflow

The future guided wizard must collect contract/solicitation, CAGE/UEI, FCI/CUI/CDI, required level/type/date, locations, systems/enclaves, official guide asset categories, CUI flows, interconnections, ESP/CSP/shared services, suppliers, remote workers, specialized/risk-managed/out-of-scope assets, assumptions, and assessor questions. Unresolved scope issues produce `SCP001` and block final readiness.
