# Standards source registry

The runtime registry accepts HTTPS primary government sources and records issuer, version, publication/retrieval dates, cache state, and SHA-256 when fetched. Authority order is regulation; FAR/DFARS clause; solicitation/contract; DoD CMMC model/scoping/assessment/hashing material; normative NIST PDF; official machine-readable catalog; official guidance; informative crosswalk; internal interpretation.

Conflicts are retained for reviewer disposition. A cached response is display/offline evidence, not activation authority. The normative PDF controls when NIST identifies it as normative.
