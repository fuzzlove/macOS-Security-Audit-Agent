# Compliance product roadmap

1. **P0_BLOCKS_VALID_ASSESSMENT:** verified catalog packs; objective-level E/I/T workflow; scope/CUI boundary; exact scoring/POA&M; reviewer and report conformance.
2. **P1_MAJOR_COVERAGE_GAP:** evidence vault access controls; SSP; provider/supplier responsibility; incident package; affirmation calendar.
3. **P2_PROFESSIONAL_MATURITY:** role workspaces, integrations, OSCAL exchange, offline review package, signed content updater.
4. **P3_FUTURE_READINESS:** complete Rev. 3 transition, DoD Zero Trust, PQC inventory, SSDF/SBOM and advanced resiliency.
5. **P4_OPTIONAL_ENHANCEMENT:** read-only external review portal and presentation refinements after assessment integrity is complete.

Each release must preserve profile isolation, historical decisions, source hashes, manual-evidence safeguards, and no automatic submission or affirmation.
