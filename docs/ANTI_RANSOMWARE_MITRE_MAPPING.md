# Anti-Ransomware MITRE ATT&CK Mapping

Mappings are produced from observed behavior, never merely because a process is unknown. Each mapping records evidence, confidence, and whether it is inferred. Candidate behaviors include Data Encrypted for Impact, Data Destruction, Inhibit System Recovery, Impair Defenses, scripting interpreters, launch agents/daemons, file discovery, and archive workflows. Exfiltration is omitted unless network or file evidence supports it.

ATT&CK mappings describe behavior; they do not establish actor or malware-family attribution.
