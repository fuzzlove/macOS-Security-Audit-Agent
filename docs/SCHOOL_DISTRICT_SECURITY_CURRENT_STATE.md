# School District Security Current State

Status: **partial readiness foundation; not a legal-compliance determination**. Reviewed 2026-07-10.

MSAA remains a macOS-focused technical evidence collector. A successful host check is supporting technical evidence only and cannot establish district-wide implementation, FERPA/COPPA/CIPA/ADA/IDEA compliance, or student safety.

## Implemented in this slice

| Capability | Evidence/scope | Privacy and accessibility boundary | Limitation |
|---|---|---|---|
| Layered applicability | Structured federal/conditional/contract/voluntary decisions | Unknown applicability stays unresolved | No activated state/territory pack |
| District assets | Criticality, data class, emergency and technical accommodation dependencies | Diagnosis/IEP/504 detail is rejected | Inventory UI/import not yet built |
| Accessibility impact gate | Blocks unsafe security actions | AAC and emergency-service interruption fail closed | Requires human accessibility review |
| Cyber containment plan | Expiration, rollback, approval, dry-run metadata | Physical emergency automation is prohibited | No live response adapter is enabled |
| Privacy default deny | Rejects high-risk surveillance absent the complete exception review | No collection is performed | Legal authority is not inferred |

## Existing collector coverage

Existing macOS configuration, integrity, alerting, evidence, and export capabilities cover one managed macOS host. Windows, ChromeOS, iOS/iPadOS, Android, Linux, network, SaaS, identity, MDM, SIEM, backup restore, and physical systems require bounded adapters or manual evidence. Missing collection is not a passing result.

## Source conclusions

- CISA's K-12 recommendations are a voluntary high-priority baseline: MFA, KEV mitigation, tested backups, exercised incident response, and training.
- Department of Education guidance states FERPA does not prescribe a complete security-control catalog.
- CIPA is conditional; the FCC Cybersecurity Pilot is separate from ordinary E-Rate.
- DOJ Title II currently incorporates WCAG 2.1 AA. WCAG 2.2 AA is tracked only as forward readiness.

All jurisdiction overlays require primary-source verification and human legal review before activation.
