# Consultant Timesheet

Consultant Timesheet is a local-first engagement journal and explicit clock. Start Assessment creates a SQL entry and event-log record; Stop Assessment calculates elapsed time and records another event. These records show when MSAA received user actions, not continuous-attention telemetry or contractual acceptance.

## How to — new to consulting

1. Enter the work/contractor name and engagement name.
2. Select **Start Assessment** when authorized billable work begins.
3. Record what you worked on, goals, completed outcomes, struggles/evidence gaps, and other approved tools.
4. Pick a standards-oriented suggestion as a reminder; it does not establish compliance.
5. Save progress during the day and select **Stop Assessment** when work ends.
6. Review the table and export Daily, Weekly, Monthly, or All entries as XLSX, DOCX, PDF, TXT, or HTML.

Do not enter credentials, sensitive client content beyond need-to-know, classified material, or unnecessary personal information. Optional office/PDF dependencies must be installed for their formats.
