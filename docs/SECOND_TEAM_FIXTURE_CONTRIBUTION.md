# Second-Team Fixture Contribution

Check out the recorded source commit and run `scripts/build_external_team_fixture.sh`. Sign only that inert fixture with the contributor’s Developer ID Application identity and hardened runtime, then run `scripts/verify_external_team_fixture.sh`.

Return the signed binary, public certificate chain, Team ID, signing identifier, designated requirement, CDHash, SHA-256, source commit, build log and verification output. Do not provide a private key, password, p12, Keychain export or Developer-account credential. The fixture contains no privileged MSAA code or network behavior and operates only in its internally generated marked temporary root.
