# DFARS cyber-incident workflow

Incident intake records contract applicability, discovery time, affected systems/contracts, CUI/CDI and operationally critical support impact, accounts, lateral access, evidence, images/packet data, malware isolation, subcontractor report numbers, legal/management review, and government requests. The system calculates 72-hour reporting and 90-day preservation deadlines but never submits to DIBNet/DC3 or transmits malware.
