# Active Containment Blockers

The machine-readable register is `ACTIVE_CONTAINMENT_BLOCKERS.json`. Implementation blockers for canonical identifiers, native helper construction, public message-bound XPC identity, contribution preflight, signing scripts and host authorization are resolved in source. Remaining gates require controlled Apple signing resources, an entitled sensor, external review, live installed tests, a second-team artifact and an authorized disposable reboot host. None is marked PASS without contributed evidence.
