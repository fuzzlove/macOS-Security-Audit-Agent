# ClickFix Campaign Mapping

The corpus maps generic, non-operational behaviors to copy/paste execution, fake verification and repair prompts, malvertising, CrashFix-style transitions, drag-to-Terminal, network-to-shell, Base64/Gzip decoding, dynamic evaluation, zsh loaders, Script Editor delivery, AppleScript URL invocation, temporary staging, LaunchAgent persistence, and credential-stealer intent.

References to Atomic Stealer-style or MacSync-style delivery describe behavioral similarity only. They contain no malware, infrastructure, payload, attribution assertion, or functioning indicator. Browser, Script Editor, unsigned-parent, and quarantine provenance fixtures are simulated endpoint telemetry because shell adapters cannot observe those facts. Operational validation requires appropriately entitled and deployed endpoint telemetry.
