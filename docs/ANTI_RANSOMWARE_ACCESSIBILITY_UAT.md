# Anti-Ransomware Accessibility UAT

Automated checks cover accessible names, selectable/copyable status text, keyboard-focusable native controls, no modal workflow, no forced timeout, text labels independent of color, and construction without service workers. Manual build-bound testing must cover VoiceOver, Full Keyboard Access, focus, text scaling/zoom, contrast/transparency, reduced motion, light/dark appearance, cognitive task flow, AAC/screen-reader continuity, and school role restrictions.
