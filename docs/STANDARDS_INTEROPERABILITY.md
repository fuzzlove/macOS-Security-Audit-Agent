# Standards Interoperability

Native control definitions carry structured mappings for NIST SP 800-53, NIST SP
800-171, CMMC, DoD and CISA guidance, PCI DSS, mSCP, MITRE ATT&CK, and MITRE D3FEND.
Only identifiers, versions, mapping types, and concise notes are stored. Mappings do
not certify compliance or imply endorsement. MSAA-native assessment JSON is used
until an exporter is validated against an applicable official OSCAL schema.
