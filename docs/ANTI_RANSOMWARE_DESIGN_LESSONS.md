# Anti-Ransomware Design Lessons

MSAA uses public endpoint-security research, incident postmortems, vendor-neutral CISA guidance, and open-source project documentation as design input, not as a source of copied code or rules.

Key lessons are to require corroborating behavioral signals, explain confidence, bound event volume, preserve metadata-first evidence, expose sensor loss, keep containment reversible and consent-driven, and treat recovery testing as part of protection. Rules or signatures require provenance and license review. GPL, proprietary, and unknown-license implementations are not copied into MSAA; resulting implementations are original and project-native.
