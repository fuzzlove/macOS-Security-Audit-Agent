# Administrator Rollout Guide

Validate scanner fixtures, adapter integrity, log permissions, configuration precedence, uninstall behavior, and emergency access on representative Intel and Apple-silicon Macs. Deploy audit mode first through MDM. Do not use environment variables to weaken managed policy. Preserve rollback records and startup-file backups. A user can recover by opening a shell without startup files and running the uninstaller; the login shell is never changed automatically.
